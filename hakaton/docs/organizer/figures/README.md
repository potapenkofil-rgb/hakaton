# Синтетические примеры графиков

Фигуры в этом каталоге показывают **форму полезной визуализации**, а не решение кейса. Данные искусственные и не используют реальные комбинации поставок, инвестиций или результатов `Топливного космоконтура 2035`.

Каждый график имеет маркировку `SYNTHETIC EXAMPLE — NOT A CASE SOLUTION`.

Назначение:

- `synthetic_supply_vs_demand.svg` — пример сравнения supply/served/demand;
- `synthetic_inventory_and_reserve.svg` — пример inventory trace относительно reserve threshold;
- `synthetic_cost_breakdown.svg` — пример decomposition расходов.

Команды могут использовать другие типы визуализаций и другой дизайн. Эти картинки не входят в критерии как обязательный UI template.
