# План работы

Команда: Филипп — ядро и API, фронтенд — интерфейс, Ваня — тесты и
проверка, Георгий — записка, презентация, защита. Этапы идут по порядку,
внутри этапа задачи параллельны. У каждой задачи есть «готово, когда» —
без этого задача не закрыта.

## Правила на всё время

1. Числа считает только `src/fuelhub`. В интерфейсе, записке и слайдах —
   ссылка на файл в `results/`, откуда число взято.
2. Файлы организаторов (`data/`, `configs/scenarios/base.yaml`,
   `mandatory_stress.yaml`, `configs/schemas/`, `tests/reference/`,
   `docs/organizer/`) не редактируются. Свои сценарии — `configs/scenarios/team_*.yaml`.
3. Каждое допущение — строка в `configs/assumptions.json`: название,
   значение, единица, источник, где применяется. Без строки допущения нет.
4. `main` всегда зелёный: `python -m pytest -q` перед пушем. Работа в
   ветках по человеку (`filipp/…`, `front/…`, `vanya/…`, `georgy/…`), в
   `main` — через merge без ревью, но с зелёными тестами.
5. Коммиты маленькие, сообщение — что изменилось по-русски.
6. Паролей, токенов и ключей в репозитории нет.
