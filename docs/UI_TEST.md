# Проверка интерфейса за 5 минут

## Запуск

Из корня репозитория:

```
set PYTHONPATH=src
python -m fuelhub serve
```

Откроется http://127.0.0.1:8765/ (порт можно сменить: `--port 9000`).
Остановить — Ctrl+C. Никаких установок не нужно, только Python 3.10+.

## Тестовые планы (`results/plans/`)

| План | Что это | BASE | MANDATORY_STRESS |
|---|---|---|---|
| `base-v1` | основной: Core + Flex, Earth-New с 2038, ISRU с 2038, ZBO в 2037, CAPEX 1790 | исполним, нарушений нет | НЕ исполним: дефицит 30 т в 2039 и 53 т в 2040, резерв 45 дней сорван |
| `stress-response` | тот же, но с 2038 добавлены заказы у Flex и бронь Emergency — то, что оператор может изменить после того, как увидел стресс | переполнение бака в 2039–2040 (заказано больше, чем нужно в спокойном году) | исполним, дефицита нет |
| `earth-only` | без Луны: Core + Flex + Earth-New, ZBO; CAPEX 540 | исполним, PV 9 467 — дешевле base-v1 | резерв сорван в 2039–2040, дефицит 31 т |
| `no-investments` | ничего не строим | дефицит 90 т в 2040, сервис 77 % | всё плохо: потери 4,5 % > 2 %, дефицит 234 т |
| `broken` | специально кривой | 11 нарушений: заказ 200 у Core при мощности 190, заказ больше брони, ISRU без финансирования, ZBO в 2035, бак 300 т при ёмкости 70 | ещё хуже |
| `invalid` | ошибки ввода | расчёта нет: отрицательный заказ, канал F, год 2041 | — |
| `v3-earth` | рекомендуемый: Earth-New + ZBO, без Луны, подобран автоматически, резерв не ниже 55 дней | исполним, PV 8 643 | резерв сорван в 2040, дефицит 141 т |
| `v3-earth-response` | ответ на стресс для v3-earth: только Flex и Emergency 2039–2040 | переполнение бака | исполним, дефицита нет, PV 10 202 |

Подробно про выбор плана и стресс: [STRESS_RESPONSE.md](STRESS_RESPONSE.md).

## Как устроена страница

Сверху одна строка: выбор плана, загрузка JSON, сценарий (две кнопки
организаторов: Стандартный и Стрессовый, рядом список «Сценарий команды…» с
шестью сценариями `TEAM_*`), кнопка «Посчитать».
Справа ссылки: сравнить сценарии, сохранить, скачать план / CSV / XLSX.
Под строкой — статус (зелёная или красная точка), потом шесть ключевых чисел,
нарушения, два графика, таблицы. Редактор плана в самом низу, за ним справочник
каналов. Пересчёт только по кнопке «Посчитать» или по Enter в поле.

## Что покликать

1. **Открыть страницу.** Сразу загружен рекомендуемый `v3-earth` в стандартном сценарии: «план исполним», нарушений нет, затраты PV 8 643, дефицит 0, мин. резерв 55 дней.
2. **Сценарий → Стрессовый.** Считается сразу. Статус красный: «план не исполним, нарушений: 1». В списке красная точка (резерв 45 дней в 2040) и две серые с пометкой «справочно» (сервис общего спроса, требование стандартного сценария). Дефицит 140,6 т и резерв 0 дней подсвечены красным. На графике запаса красные квадраты в месяцах с дефицитом.
3. **«Сравнить сценарии».** Внизу таблица: исполним да / нет, затраты 10 732 против 11 269, дефицит 0 против 140,6 т, дефицит и резерв по годам.
3а. **План → `v3-earth-response`, сценарий Стрессовый.** Исполним, дефицита нет, PV 10 202: это ответ на пункт 2, меняет только Flex и Emergency 2039–2040. Переключить на Стандартный — переполнение бака.
3б. **Сценарий команды → «Высокий спрос организаторов».** Для `v3-earth` семь нарушений: резерв и сервис с 2038. Кнопки организаторов гаснут, список подсвечен. Обратно: нажать «Стандартный».
4. **Поменять число.** Прокрутить к «Решения плана», у Earth-Core 2035 поставить заказ 200 вместо 95, нажать Enter. Нарушение «Превышена мощность»: заказ 200 т при мощности 190. Вернуть 95, Enter — нарушение исчезает.
5. **Снять галочку ZBO, «Посчитать».** В стрессе появится «Потолок потерь» 2038–2040, в BASE — «Переполнение бака». Вернуть.
6. **План → `invalid`.** Красный статус «План не принят, расчёта нет» и строки с ошибками: отрицательный объём, неизвестный канал F, год 2041. Старые результаты остаются, но затемнены.
7. **План → `broken`.** 11 нарушений, у каждого год, правило и причина словами.
8. **План → `base-v1`, в поле «Название» написать `my-test`, «Сохранить».** Статус «Сохранено: results/plans/my-test.json», план появился в списке. Обновить страницу (F5), выбрать `my-test` — все числа те же. Название менять обязательно: сохранение под старым именем перезаписывает файл плана вместе с текущим сценарием.
9. **Скачать CSV / XLSX.** Скачивается `my-test_BASE.csv` (год, сущность, показатель, значение, единица) или `.xlsx` с листами по таблицам. Числа совпадают с экраном.
10. **План → `base-v1`, сценарий Стрессовый.** Не исполним: дефицит 30 т в 2039 и 53 т в 2040. План → `stress-response`: исполним, но `python tools/check_response.py base-v1 stress-response` показывает, что он меняет 2038 год, то есть нарушает срок реакции. Правильный ответ смотреть в пункте 3а.

## Если что-то не так

- Страница пустая или красная «Ошибка» вверху — посмотреть консоль браузера (F12) и вывод сервера в терминале.
- «Address already in use» — порт занят, запустить с `--port 9000`.
- Числа на экране не совпадают с `python -m fuelhub calc results/plans/base-v1.json` — это баг, писать Филиппу.
