# Топливный космоконтур 2035

КосмоХакатон 2026, кейс 2 (АНО «КЭП»). Инструмент оператора орбитального
топливного узла: планирование поставок, запасов, резервов мощности и
инвестиций на 2035–2040 с проверкой ограничений в стандартном и стрессовом
сценариях.

## Структура

| Папка | Что лежит | Кто правит |
|---|---|---|
| `data/` | исходные данные организаторов (CSV), не редактируются | никто |
| `configs/scenarios/` | сценарии организаторов `base.yaml`, `mandatory_stress.yaml`; свои сценарии — `team_*.yaml` | организаторские — никто, свои — команда |
| `configs/schemas/` | JSON-схемы плана, выгрузки и данных от организаторов | никто |
| `configs/assumptions.json` | допущения команды: название, значение, единица, источник, где применяется | команда |
| `src/fuelhub/` | расчётное ядро и API | бэкенд |
| `tests/` | тесты; `tests/reference/` — контрольные примеры V01–V10 и невалидные планы от организаторов | тестирование |
| `results/` | сохранённые планы, выгрузки, сравнение сценариев | генерируется |
| `docs/` | записка, резюме, презентация, схемы, источники; `docs/organizer/` — правила расчёта и FAQ организаторов; `docs/case/` — постановка и критерии (PDF) | документы |

Материалы организаторов взяты из https://github.com/SpaceEconomyPolicy/test_oil,
коммит `cec6de1` от 2026-09-18.

## Запуск

Появится вместе с кодом. План: Python 3.10+, без внешних зависимостей для
ядра; `python -m pytest -q` для проверки; одна команда для запуска
интерфейса.

## Порядок проверки (как у организаторов)

1. установка и запуск;
2. стандартный сценарий `BASE`;
3. обязательный стресс `MANDATORY_STRESS`;
4. дополнительные тесты команды;
5. сравнение сценариев и выгрузка CSV/XLSX.
